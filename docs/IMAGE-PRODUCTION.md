# Plan de imágenes para Obra.com.py

## Estado actual

Las cuatro fotografías WebP utilizadas son imágenes referenciales. La interfaz las rotula de forma visible y nunca las describe como trabajos realizados por Obra.

## Reemplazos prioritarios

1. Hero: obra real terminada, horizontal, con permiso del cliente.
2. Casa llave en mano: exterior y dos detalles de terminación.
3. Piscina: estructura en obra y resultado final.
4. Quincho: vista general y detalle de parrilla/mesada.
5. Remodelación: antes y después desde el mismo ángulo.
6. Equipo en obra: solo personas reales y autorizadas.

## Reglas

- Registrar autor, fecha, permiso y proyecto en un inventario.
- No usar imágenes generadas como prueba de experiencia.
- WebP, ancho suficiente para el slot y compresión para móvil.
- Hero sin `loading=lazy`; imágenes bajo el fold con carga diferida.
- Alt text describe la escena sin rellenar palabras clave.
